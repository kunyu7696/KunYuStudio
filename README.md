#昆宇工作室

>原kunyuecosystem

我的世界模组与整合包的可视化开发工作台：把“写模组”从手写Java/JSON变成
"AI生成→沙盒验证→一键导出"的闭环.桌面应用(电子)，车窗优先。

## 功能一览

- **统一可视化编辑器**：物品 / 方块 / 实体 / 食物 / 工具 / 护甲 / 附魔 / 药水 /
  生物群系 / 进度，同一份语义模型驱动，实时预览。
- **代码手工编写**：可视化不是唯一路径——打开项目即是完整代码工作区（侧边栏文件树
+摩纳哥编辑器），可直接手写/修改Java、JSON、Gradle等产物，多标签页、
  自动保存、错误行跳转、运行前后 diff；生成器会保留你在表单里填的「自定义代码片段」。
- **AI流水线**：五档Agent(迅工/匠造/大师/桥接/织星)，
理解 → 生成 → 构建 → 测试 → 导出全链路；构建失败自动读日志修复
  （按档位 0/1/3/4/5 轮），真机测试自愈至多 10 轮。单次运行有资源熔断：
模型调用上限24/48/72/96/144次、Gradle构建3/6/10/12/14次、
墙钟30/60/90/120/150分钟，任一超限即熔断停止并如实回报.
- **贴图 / 模型**：像素画生成（512px 大图 → 量化降采样）、自研建模器支持
立方体/骨骼/网格/UV/权重/动画，`.bbmodel` 互导；离线时程序化保底。
- **整合包组装**：Modrinth/CurseForge搜索入库，拖拽组装，一键导出，
可直发双平台。
- **零配置运行环境**：应用不内置 JDK 与游戏本体——首次使用在「设置 → 运行环境」
一键准备，按版本矩阵自动检测/下载所需JDK（17/21/25）与我的世界客户端、
  依赖库、资产，生成可直接启动的托管实例；国内可配置镜像（BMCLAPI 失败自动回退
  官方源），已下载文件校验跳过、支持断点续传。
- **真机沙盒**：observer mod随包分发，游戏内截图/世界探测/输入注入，
全自动配子试验闭环验证。
- **MCP生态**内部mcdev-mcp静态检查；自定义mcp设备接入(stdio)，
  市场预置一键导入，工具级权限过滤（市场新装插件默认不暴露任何工具，需在
  插件页「工具权限」逐项勾选放行）。
- **性能画像**：火花/JFR报告解析，mod性能榜单与优化建议.

## 快速开始

前置：Node.js≥22(开发本应用用).模组项目所需的JDK与我的世界运行时
**无需预装**——首次使用时在「设置 → 运行环境」一键准备，应用按版本矩阵自动
检测/下载。

```PowerShell
npm ci
npm run dev
```

即可启动开发模式（界面语言：中文）。创建第一个项目后，试试顶栏「⚡ 快速创建」。

### 打包前置（`构建：赢得` 之前）

1. `资源/观察员-模式` 下执行一次 `gradlew构建`(jdk17)--产出游戏内
观察mod jar；
2. `npm运行提取模型`——把离线嵌入模型拉进 `资源/模型`
   （可选，缺失时运行时回退在线下载）。

## 隐私与合规

- **单机本地优先**：项目、设置、AI密钥全部保存在本机userdata；
密钥经系统钥匙串加密(Windows DPAPI/macOS密钥链)。
  **明文回退说明**：`safestorage` 不可用（如部分 Linux 发行版无钥匙串）时，
  密钥退回明文保存并在启动日志显式告警；此类环境下请勿把 userData 目录
  同步到公共网盘。

按清单下载(EULA合规).

## 已知环境问题

部分企业 EDR / 安全软件会拦截 `node_modules` 内进程的目录枚举与内存映射，
导致esbuild/电子无法启动。`npm run dev`已内置规避（把二进制复制到
TEMP 并重定向），无需手动处理；如仍失败请查看 `scripts/run-electron-vite.cjs`
头部注释。

### 开发模式安全削弱说明（仅 dev，生产构建不受影响）

`npm run dev` 为兼容上述 EDR 环境与 Vite 开发服务器，会在启动时叠加两层削弱：

1. **`--no-sandbox`+禁用GPU子进程**：受限会话中铬砂箱无法初始化，
   仅本机驱动探针等自动化场景使用；生产构建保持 sandbox 开启。
2. **`webSecurity` 放宽**：仅当存在 `electron_RENDER_URL`(Vite开发服务器)时
放宽跨域限制；生产构建强制启用WebSecurity与同源策略。

以上削弱均通过环境变量检测自动切换，不会带入 `npm运行生成：win` 产物。`npm运行生成：win` 产物。

另：**CSP不随开发/生产变化**——`index.html` meta 静态声明
`Default-Src'self'；script-src'self'`（无`unsafe-eval`），`style-src`放行
`'不安全内联'`供element Plus内联样式，`connect-src`放行`WS：` 与
`127.0.0.1/localhost`供Vite HMR、观察者探针与本机MCP桥接.
