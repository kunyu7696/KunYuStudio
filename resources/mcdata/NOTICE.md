# 数据来源与许可

本目录随 KunYu Studio 分发 Minecraft 结构化数据子集，来源：

**minecraft-data** — https://github.com/PrismarineJS/minecraft-data
License: MIT（© PrismarineJS contributors）

仅提取 Java 版（pc）1.20 / 1.20.1 共享数据的精选文件（blocks、items、entities、
enchantments、effects、biomes、particles、foods、recipes、materials、instruments、
blockLoot、entityLoot、language、version），未做内容修改；
`zh-aliases.json` 为坤舆原创的高频条目中文别名种子词典，与 Minecraft 官方译名可能存在差异。

Minecraft 版权归 Mojang Studios / Microsoft 所有；本数据仅用于开发期注册名/数值查询。
